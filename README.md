# Cutlist

A free cut list optimiser for sheet goods: enter stock sheets and rectangular parts, get guillotine
cut layouts with waste, cut count and offcuts.

Live at <https://xdgfx.github.io/cutlist/>.

- Everything runs in the browser. Jobs and history are saved in local storage.
- Each calculation is kept in history, and each offers several candidate layouts to choose between.
- "Copy link to this job" puts the whole job in the URL.

```sh
npm install
npm run dev
npm test
npm run build
```
